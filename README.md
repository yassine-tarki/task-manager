# Task Manager

A simple Python console app to manage daily tasks.

## Features

- **1. Add a task**: empty titles are rejected
- **2. Display tasks**: shows each task with its number
- **3. Search**: finds tasks that contain a keyword
- **0. Exit**

## How to run

Open the folder in VS Code, open `main.py` and click **Run Python File**.
